# Kültür style guide

## All languages

- A critical, opinionated voice about the music is welcome. Opinion sits in sections marked as opinion and never carries a factual claim.
- Facts about an artist (releases, dates, quotes, events) need sources like any other claim.
- Never cover private lives. Political statements, court cases and bans go to an editor.
- Album, song and venue names keep their original Turkish spelling in every language.

## tr (Turkish, primary)

- Standard written Turkish with correct diacritics (ç, ğ, ı, İ, ö, ş, ü).

## en (English)

- Plain international English. Gloss Turkish terms on first use.

## fa (Persian)

- Standard written Persian with zero-width non-joiners. Transliterate Turkish names on first use and keep the original in Latin script in parentheses.
