# Artist story: writing guide

- One artist per story: background, key works, and what the artist and critics have said.
- A critical, opinionated voice about the music is welcome. Put opinion in sections marked `opinion: true`; those sections carry no factual claims.
- Facts about the artist (dates, releases, quotes, events) need sources like any other claim.
- Never write about the artist's private life. Political statements, court cases and bans are a restricted beat and go to an editor.
- 1,000–1,500 words.
